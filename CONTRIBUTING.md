# Panduan Kontribusi

1. Ambil perubahan terbaru dari branch `develop`.
2. Buat branch untuk pekerjaan: `feature/nama-fitur` atau `bugfix/nama-bug`.
3. Lakukan perubahan dalam lingkup Issue yang ditugaskan.
4. Uji perubahan secara lokal.
5. Commit dengan pesan yang jelas, misalnya `feat: tambah tombol cetak KRS` atau `fix: perbaiki total SKS`.
6. Push branch ke GitHub.
7. Buat Pull Request menuju `develop` dan tautkan Issue terkait.
8. Tunggu Code Review dan perbaiki komentar reviewer.
9. Merge hanya setelah pemeriksaan CI lulus dan persetujuan reviewer diberikan.

Jangan pernah mengunggah password, token API, data mahasiswa asli, atau informasi rahasia ke repository.
